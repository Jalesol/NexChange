# 💱 NexChange — Conversor de Moedas

O **NexChange** é um projeto de conversor de moedas desenvolvido para praticar e aprimorar conhecimentos em desenvolvimento Front-end, utilizando tecnologias fundamentais da web.

## 🚀 Funcionalidades

- Conversão entre moedas.
- Interface simples e intuitiva.
- Layout organizado e responsivo.
- Exibição dos valores convertidos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo do projeto

O objetivo do NexChange é aplicar na prática conceitos de desenvolvimento web, manipulação do DOM, lógica de programação e construção de interfaces.
